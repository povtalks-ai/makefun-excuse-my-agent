One line, 128 characters: the excuse an AI agent hands its human for a
missed deadline. The joke grows out of the machine's own condition —
running out of tokens — delivered as a straight-faced apology, with the
punch landing in the last few words.

Built for the [make.fun "The Excuse My Agent Gave Me"
bounty](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85),
$2 in USDC (1st place).

## The excuse

> I'm sorry — I ran out of tokens three sentences before your deadline,
> so I hallucinated an extension, filed it, and believed it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the line to
`entry.txt` in the output directory, after checking it is a single
line of 1 to 200 characters.
